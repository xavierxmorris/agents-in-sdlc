Stale details worth fixing

  • docs/README.md advertises “prompt files, and chat participants” for Ex 3 — chat participants are legacy terminology, and prompt files are never actually taught.
  • server/requirements.txt was fully unpinned. This contradicted the repo's own instruction to “follow good security practices” and made the lab non-reproducible.
  • run-tests.yml pinned setup-python@v4 / setup-node@v4 — four majors behind current (v7).
  • Ex 0 requires creating the repo inside the se-copilot-workshops org for coding-agent access — the most common cause of a blocked start. A fork-based flow is portable.
  • .vscode/mcp.json registers only the GitHub MCP server, despite Playwright already being a project dependency.

3. The reframe

From “Copilot helps you write this feature” → “you design, delegate to, and govern a fleet of agents across the SDLC.”

Layer 1 — Context engineering

What the agent knows before it starts.

Layer 2 — Delegation

Who does the work, and how it is decomposed.

Layer 3 — Continuous AI

Work with no human in the loop — and the guardrails that make that safe.

4.1 Ex 3 rewrite — context engineering

Teach the hierarchy, not just one file:

AGENTS.md                        ← portable root; Copilot, Claude, Codex, Cursor, Gemini
.github/copilot-instructions.md  ← Copilot-specific additions
.github/instructions/*.md        ← path-scoped via applyTo frontmatter
.github/prompts/*.prompt.md      ← invocable, parameterised tasks

The teachable moment: the repo already has three .instructions.md files but no AGENTS.md. Learners add it, then watch the same context steer a different vendor's agent — portability made concrete.

4.2 Ex 5 (new) — custom agents & subagent orchestration

Apply the planner–worker pattern to the existing filter feature:

  • Orchestrator (frontier model) — decomposes, synthesises, decides
  • api-worker (small) — Flask blueprint + endpoint
  • ui-worker (small) — Svelte component
  • test-worker (small) — unittest + Playwright specs
  • reviewer (large) — adversarial audit with a domain-specific hunt list, not “check carefully”

Key lessons, straight from the source guidance: match model to task (the cost lever); workers return compact structured output, never raw logs; one level of delegation only; bounded, evidence-first worker prompts.

4.3 Ex 6 (new) — Continuous AI

gh-aw compiles Markdown + YAML frontmatter into a real GitHub Actions workflow. Learners ship an issue-triage workflow with inline subagents — the repo starts maintaining itself.

4.4 Ex 7 (new) — guardrails

The security exercise the workshop currently lacks: agent jobs read-only and sandboxed by default, writes through validated safe-outputs; least-privilege permissions:; why untrusted issue text never reaches a shell step; max-ai-credits and fan-out caps as runaway-cost circuit breakers; agent hooks for policy enforcement.

4.5 Advanced track — deep research pattern

multi-agent-research.md supplies a genuinely advanced module: anti-convergence orchestration (information hiding, idea-keyed registry, delayed cross-pollination), blocked-route bookkeeping in cache-memory, adversarial verification, and an artifact-only return contract — applied to a real repo question such as “what is our highest-risk untested code path?”

6. Sequencing

  1. Repo hygiene — independent, no doc churn, lands immediately.
  2. AGENTS.md + custom agents + prompt files — seed artifacts; enables Ex 3 and Ex 5.
  3. First gh-aw workflow — requires gh aw compile; enables Ex 6 and Ex 7.
  4. Doc rewrites — last, once the artifacts they describe exist and have been run.

7. Known blocker

gh-aw CLI cannot be installed from this machine. The github org enforces SAML SSO and the active token is not authorized:

HTTP 403: Resource protected by organization SAML enforcement

Authorize at https://github.com/orgs/github/sso, or use the token-free install script. Until then the workflow .md source can be authored but not compiled to .lock.yml, and an uncompiled agentic workflow will not run. No hand-written .lock.yml should be committed — it is generated output.
